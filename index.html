سياسة الخصوصية لتطبيق أدويتي

جمع البيانات

لا يقوم تطبيق "أدويتي" بجمع أو إرسال أي بيانات شخصية إلى خوادم خارجية، ولا يتطلب إنشاء حساب أو تسجيل دخول.

قد يقوم المستخدم بإدخال بياناته بنفسه داخل التطبيق، مثل الأدوية والمواعيد والملاحظات، ويتم حفظ هذه البيانات محليًا على جهاز المستخدم فقط، ولا يتم نقلها أو مشاركتها خارج الجهاز.

تخزين البيانات

جميع البيانات التي يقوم المستخدم بإدخالها داخل التطبيق، مثل:

  • الأدوية
  • المواعيد
  • الملاحظات
  • الكميات والتنبيهات

يتم حفظها محليًا على جهاز المستخدم فقط، ولا يتم إرسالها إلى أي خادم أو قاعدة بيانات خارجية.

الاتصال بالإنترنت

يمكن استخدام التطبيق بدون اتصال بالإنترنت، ولا يتم استخدام الإنترنت لرفع بيانات المستخدم.

مشاركة البيانات

لا يقوم التطبيق بمشاركة أي بيانات مع أطراف ثالثة.

الإعلانات وخدمات التحليل

لا يحتوي التطبيق على إعلانات، ولا يستخدم أي أدوات تحليل أو تتبع.

التنبيهات

قد يستخدم التطبيق تنبيهات محلية على الجهاز لتذكير المستخدم بالمواعيد أو الأدوية. هذه التنبيهات يتم إنشاؤها محليًا ولا يتم إرسالها عبر أي خادم خارجي.

النسخ الاحتياطي والتصدير

في حال استخدام خاصية النسخ الاحتياطي أو التصدير أو الاستيراد، يكون المستخدم مسؤولًا عن الملف الناتج ومكان حفظه أو مشاركته. لا يقوم التطبيق برفع هذه البيانات تلقائيًا إلى أي خادم.

حذف البيانات

يمكن للمستخدم حذف بياناته من داخل التطبيق. كما أن حذف التطبيق قد يؤدي إلى إزالة البيانات المخزنة محليًا على الجهاز، وذلك حسب إعدادات الجهاز.

أمان البيانات

نظرًا لأن جميع البيانات يتم حفظها محليًا، فإن المستخدم مسؤول عن حماية جهازه والملفات التي يقوم بتصديرها.

الكاميرا والملفات

قد يطلب التطبيق إذن الوصول إلى كاميرا الجهاز أو معرض الصور أو مدير الملفات، وذلك فقط عند استخدام ميزات تتطلب ذلك مثل تصوير الأدوية أو إرفاق ملفات.

يتم طلب هذه الأذونات بموافقة المستخدم، ولا يتم استخدام هذه البيانات أو نقلها خارج الجهاز، حيث يتم حفظها محليًا فقط.

إخلاء المسؤولية الطبية

تطبيق "أدويتي" هو أداة تنظيمية فقط، ولا يقدم أي استشارة طبية أو تشخيص أو توصيات علاجية أو معلومات دوائية. يجب الرجوع إلى المختصين في حال الحاجة الطبية.

Privacy Policy for Adwiaty App

This policy explains how the "Adwiaty" app handles user data. We respect your privacy and are committed to not collecting or sharing any personal information.

Data Collection

Adwiaty does not collect or transmit any personal data to external servers. The app does not require account creation or login.

Users may enter their own data within the app, such as medications, appointments, and notes. This data is stored locally on the user's device only and is never transferred or shared outside the device.

Data Storage

All data entered by the user within the app, such as:

  • Medications
  • Appointments
  • Notes
  • Quantities and reminders

is stored locally on the user's device only and is never transmitted to any external server or database.

Internet Connectivity

The app can be used fully offline. The internet is not used to upload any user data.

Data Sharing

The app does not share any data with third parties.

Ads and Analytics

The app contains no advertisements and does not use any analytics or tracking tools.

Notifications

The app may use local device notifications to remind users of appointments or medications. These notifications are generated locally and are not sent through any external server.

Backup and Export

When using the backup, export, or import features, the user is responsible for the resulting file and where it is saved or shared. The app does not automatically upload this data to any server.

Data Deletion

Users can delete their data from within the app. Uninstalling the app may also remove locally stored data, depending on the device settings.

Data Security

Since all data is stored locally, the user is responsible for securing their device and any files they export.

Camera and File Access

The app may request permission to access the device camera, photo gallery, or file manager, only when using features that require it, such as photographing medications or attaching files.

These permissions are requested with the user's consent. The associated data is not used or transferred outside the device and is stored locally only.

Medical Disclaimer

Adwiaty is an organizational tool only. It does not provide medical advice, diagnoses, treatment recommendations, or pharmaceutical information. Please consult a qualified healthcare professional for any medical needs.

Changes to This Privacy Policy

This policy may be updated when new features are added to the app.
